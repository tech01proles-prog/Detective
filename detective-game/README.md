# Detective Noir - Браузерная детективная игра

## 🎮 Описание

Детективная игра в стиле нуар с возможностью создания и загрузки пользовательских сценариев.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Сервер
cd detective-game/server
npm install

# Клиент
cd ../client
npm install
```

### 2. Запуск

```bash
# Терминал 1 - Сервер (порт 3001)
cd detective-game/server
node index.js

# Терминал 2 - Клиент (порт 5173)
cd detective-game/client
npm run dev
```

### 3. Открыть в браузере

Перейдите на `http://localhost:5173`

## 🎯 Как играть

1. **Загрузите сценарий** через главное меню (импортируйте JSON файл)
2. **Исследуйте локации** - перемещайтесь по карте города
3. **Собирайте улики** - осматривайте места и говорите с персонажами
4. **Допрашивайте подозреваемых** - используйте ветвящиеся диалоги
5. **Вынесите вердикт** - когда собрано достаточно улик, обвините преступника

## 📝 Формат сценария (JSON)

Сценарий включает:
- **Локации** с координатами на карте и связями
- **NPC** с деревьями диалогов
- **Улики** различных типов (текст, фото, аудио, документы)
- **Подозреваемых** с условиями обвинения
- **Взаимодействия** для исследования

Пример структуры см. в `demo-scenario.json`.

## 🔧 API Endpoints

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| GET | `/api/scenarios` | Список сценариев |
| GET | `/api/scenarios/:id` | Получить сценарий |
| POST | `/api/scenarios` | Создать сценарий |
| PUT | `/api/scenarios/:id` | Обновить сценарий |
| DELETE | `/api/scenarios/:id` | Удалить сценарий |
| POST | `/api/saves` | Сохранить игру |
| GET | `/api/saves/:id` | Загрузить игру |
| POST | `/api/upload` | Загрузить файл |

## 🎨 Стиль

- **Мрачный нуар** - тёмная цветовая палитра
- **Золотые акценты** - для важных элементов
- **Красный** - для опасности/обвинений

## 🛠️ Технологии

**Frontend:**
- React 18 + TypeScript
- Vite (сборка)
- TailwindCSS (стили)
- Lucide React (иконки)

**Backend:**
- Node.js + Express
- better-sqlite3 (база данных)
- Multer (загрузка файлов)

## 📋 Требования

- Node.js 18+
- Ubuntu Server (или любая ОС с Node.js)
- Десктопный браузер (Chrome, Firefox, Edge)
